💉 SQL Injection

SQL Injection е уязвимост, при която attacker може да inject-не SQL код в database заявка.

Това става когато сайтът слага user input директно в SQL query.

SELECT * FROM users WHERE username='$user' AND password='$pass';

Ако input-ът не е защитен, attacker може да промени логиката на заявката.

Един от най-известните payload-и е:

' OR '1'='1

'1'='1' винаги е TRUE.

Така login системата може да мисли че authentication-ът е успешен.

⚠️ Cross Site Scripting (XSS)

XSS позволява attacker да inject-не JavaScript в web страницата.

Това се случва когато сайтът render-ва user input без filtering.

Пример:

<script> alert(1) </script>

Browser-ът ще изпълни JavaScript кода.

MISSION:

Опитай да inject-неш HTML.

🔓 IDOR

IDOR означава: Insecure Direct Object Reference.

Това се случва когато сайтът не проверява authorization-а правилно.

/profile?id=1

Ако attacker смени ID-то, може да достъпи чужди данни.

MISSION:

Намери admin profile-а.
