This project is a Bulgarian-language educational website focused on web application security. The goal is to explain common web vulnerabilities in a clear and accessible way, helping beginners understand how attacks work and how they can be prevented.

Current topics include vulnerabilities such as:

Cross-Site Scripting (XSS)
SQL Injection (SQLi)
Authentication and authorization issues
Other common web security concepts

THe idea of the project:

The idea behind this project is to create a centralized learning resource for Bulgarian-speaking users interested in cybersecurity and web security.

Many high-quality security resources exist in English, but there are significantly fewer beginner-friendly materials available in Bulgarian. This website aims to help bridge that gap by providing explanations, examples, and educational content in Bulgarian.

Details:

The project was originally designed as a frontend-only website using HTML, CSS, and JavaScript.

The initial goal was to focus on delivering educational content through a simple and accessible interface without requiring a backend or user accounts.

However, the project is expected to evolve over time and may eventually include additional functionality such as:

Interactive demonstrations
Quizzes and challenges
User accounts
Progress tracking
Backend services and databases
Additional cybersecurity topics

Goals:

 Make cybersecurity concepts more accessible to Bulgarian learners
 Provide practical explanations rather than only theoretical descriptions
 Continuously expand the available educational content
 Serve as a long-term learning platform rather than a one-time project
 Personal project and self-learning coding

The project is actively being developed and expanded.

Feedback, suggestions, and contributions are welcome.
